# 履修ナビ（期末発表用プロトタイプ）

成績PDFから卒業要件の過不足を可視化し、履修計画を提案する**スマホ向けWebアプリ**のプロトタイプです。
ビルド不要・サーバー不要の静的ファイルだけで動きます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面本体（ランディング / ローディング / ダッシュボード） |
| `style.css` | スマホ優先のデザイン |
| `data.js` | **サンプルデータ**（卒業要件・科目・修得済み科目） |
| `app.js` | 集計・描画・PDF読み取り・履修計画 |
| `qr.html` | 公開URLから発表用QRコードを作るページ |
| `manifest.json` | PWA設定（アプリ名・アイコン・起動方法） |
| `sw.js` | Service Worker（2回目以降オフラインでも起動） |
| `icons/` | ホーム画面用アイコン（`tools/make_icons.py` で再生成可能） |
| `.nojekyll` | GitHub Pages で不要な処理を止める空ファイル |

## ローカルで見る

```powershell
cd rishi-navi
python -m http.server 5500
```

ブラウザで `http://localhost:5500/` を開く。
スマホ実機で見る場合は、PCと同じWi-Fiにつないで `http://<PCのIPアドレス>:5500/` を開く。

> 注意：学校のWi-Fiは端末間通信が遮断されていることがあります。その場合は下の「公開」を使ってください。

## 公開してQRにする（GitHub Pages）

1. GitHub で新しいリポジトリを作る（Public）。
2. `rishi-navi` フォルダ**の中身**をリポジトリ直下にアップロードする
   （`index.html` がリポジトリ直下に来るように。`rishi-navi/` フォルダごと入れない）。
3. **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `/ (root)` → Save**。
4. 1〜2分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` が公開される。
5. `qr.html` を開き、そのURLを入力 → QR画像を保存 → スライドに貼る。

> `.nojekyll` は入れてあります（そのままでOK）。
> 更新したら `git push` するだけで反映されます（数分かかることがあります）。

別案：**Netlify Drop**（https://app.netlify.com/drop にフォルダをドラッグ）でも同じものが公開できます。

## スマホで「アプリ」として開く（PWA）

公開URLをスマホのブラウザで開き、ホーム画面に追加すると、アドレスバーなしの全画面アプリとして起動します。

- **iPhone（Safari）**：共有ボタン →「ホーム画面に追加」
- **Android（Chrome）**：右上メニュー →「アプリをインストール」

2回目以降はオフラインでも画面が開きます（PDF解析だけは通信が必要）。

## 発表の流れ（3分）

| 時間 | 内容 |
|---|---|
| 0:00 | 「履修登録、何を取ればいいか分からない」という課題提示 |
| 0:20 | スライドのQRを表示し、観客にスマホで開いてもらう |
| 0:40 | 「サンプルで試す」→ ダッシュボード |
| 1:10 | 単位の過不足、必修の取り漏れを見せる |
| 1:40 | 科目を選ぶ → 合計単位が変わるのを見せる |
| 2:10 | 「履修計画を見る」でまとめ |
| 2:30 | 技術：PDFは端末内で解析、データはUNIPA |
| 2:50 | 今後：AIによる最適化、他学部展開 |

## 本物のデータに差し替える

`data.js` の3か所を書き換えるだけで動きます。

1. `categories` … 科目区分と必要単位数
2. `courses` … 開講科目（`code` は科目コード、`required: true` が必修）
3. `transcript` … 修得済みの科目コード一覧

> 科目名の照合は科目コード優先。名称は表記ゆれがあるので、コードを必ず入れてください。

## 注意

- 表示している大学名・学部名・科目・単位数はすべて**サンプル**です。
- PDF読み取りは pdf.js をCDNから読み込むため、PDF解析には通信が必要です（画面自体は2回目以降オフラインでも起動）。
- Service Worker は `https://` か `http://localhost` でのみ動きます（`file://` で開くとPWA機能は無効）。
- 実際の履修登録システム（UNIPA）とは連携していません。
